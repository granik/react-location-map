# Interactive location map for React
## Setup Instructions (demo)

1. Install the right npm version using NVM, run npm install:
```
nvm install
nvm use

npm install
```

2. Run the demo:
```
npm start
```

3. In browser go to localhost URL displayed in console. E.g. `http://localhost:5173`
